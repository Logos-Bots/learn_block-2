# Контент-Хаб (Content-Hub)

Интерактивная веб-панель управления контентом с поддержкой светлой и темной тем, адаптивным дизайном и полным функционалом CRUD операций для постов.

## 🎯 Цель проекта

Создание адаптивного веб-приложения для управления публикациями с возможностью:

- Просмотра ленты постов с фильтрацией по категориям и статусам
- Поиска публикаций в реальном времени
- Детального просмотра поста в модальном окне
- Создания и редактирования публикаций через форму с валидацией
- Управления лайками и закладками
- Переключения между светлой и темной темой оформления

## 📦 Установка и запуск

### Требования

- Node.js >= 18.0.0
- npm >= 9.0.0 или yarn >= 1.22.0

### Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/your-username/content-hub.git
cd content-hub

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

После запуска dev-сервера откройте [http://localhost:5173](http://localhost:5173/) в браузере.

## 🏗 Архитектура

### Модульная архитектура

- **ES6 Modules:** Каждый компонент — отдельный модуль
- **Чистые функции:** Рендеринг через функции-генераторы HTML
- **Event Delegation:** Оптимизация обработчиков событий
- **State Management:** Централизованное хранилище + localStorage

### Поток данных

1. **Инициализация:** `api.init()` загружает данные с JSONPlaceholder
2. **Обогащение:** Добавление моковых полей (категории, статусы, лайки)
3. **Рендеринг:** Проверка на пустоту → Empty State или сетка постов
4. **Взаимодействие:** Фильтрация, поиск, создание, редактирование, удаление

## 🧩 Компоненты

### Header (Шапка)

- **Desktop:** Логотип, поле поиска, переключатель темы, кнопка "Создать пост", аватар
- **Mobile:** Логотип, иконка поиска, переключатель темы
- ❌ **Кнопка уведомлений отсутствует**

### Empty State (Пустое состояние)

Отображается когда:

- Массив постов пуст (первая загрузка)
- После фильтрации не найдено ни одного поста

Содержит:

- Иконку документа (адаптируется под тему)
- Заголовок "Публикаций пока нет"
- Описание с инструкцией
- Кнопку "+ Создать первый пост"

### Sidebar (Desktop)

- Список категорий со счетчиками
- Фильтр по статусам (Опубликовано, Черновики, Архивировано)
- Активная категория подсвечивается синим

### Mobile Navigation

- **Top:** Горизонтальный скролл категорий (Pills)
- **Bottom:** Вкладки "Посты", "Создать (+)", "Профиль"

### Post Card (Карточка поста)

- Градиентная шапка (цвет зависит от категории)
- Бейджи категории и статуса
- Заголовок (обрезка 2 строки)
- Футер с датой, временем чтения, просмотрами и лайками

### Модальные окна

- **Post Detail Modal:** Полный просмотр поста с цитатами, тегами, кнопками редактирования
- **Create Post Modal:** Форма создания/редактирования с динамической сменой темы хедера

## 🔧 API Интеграция

### JSONPlaceholder Endpoints

```javascript
// Получение постов
GET https://jsonplaceholder.typicode.com/posts?_limit=20

// Получение пользователей
GET https://jsonplaceholder.typicode.com/users
```
### Mock Enrichment

Так как JSONPlaceholder не возвращает категории, статусы, лайки и просмотры, данные обогащаются при инициализации:

```JS
const categories = ['tech', 'design', 'business', 'science', 'culture'];
const statuses = ['published', 'draft', 'archive'];
// Генерация случайных значений на основе id поста
```
### CRUD Операции

|Операция|Метод|Описание|
|---|---|---|
|Создать пост|POST (mock)|Добавление в начало списка|
|Обновить лайк|PATCH (mock)|Оптимистичное обновление UI|
|Удалить пост|DELETE (mock)|Анимация удаления + API запрос|
|Редактировать|PUT (mock)|Открытие формы с данными|

## ✅ Чек-лист приёмки

### Структура и Header

- Кнопка переключения темы видна на Desktop, Tablet и Mobile
- Кнопка уведомлений (колокольчик) ОТСУТСТВУЕТ везде
- На мобильных в хедере есть иконка поиска

### Empty State

- При отсутствии постов отображается центрированный блок
- Иконка адаптируется под тему (Light: `bg-blue-50`, Dark: `bg-blue-900/30`)
- Есть заголовок "Публикаций пока нет" и описание
- Есть кнопка "+ Создать первый пост"
- После создания поста Empty State исчезает

### Темы

- Переключатель темы работает и сохраняется в localStorage
- Авто-определение системной темы (`prefers-color-scheme`)
- Все цвета соответствуют дизайн-токенам
- Плавный переход между темами

### Компоненты

- Sidebar с категориями и статусами (Desktop)
- Mobile Navigation (Pills + Bottom Bar)
- Grid адаптивный (1/2/3 колонки)
- Карточки с градиентами категорий
- Модальные окна (Post Detail, Create Post)
- Валидация форм с визуальной обратной связью

### Функционал

- Поиск фильтрует по заголовку и содержанию (debounce 300ms)
- Фильтр по категориям и статусам работает
- Лайки переключаются
- Создание/редактирование/удаление постов
- Ошибки API обрабатываются

- ESLint без ошибок
